# FuseDrift

FuseDrift enables High-Performance Distributed Computing through Real-Time Processing and Auto-Scaling Engine Pipeline Management.

The key benefits of using FuseDrift include:

- FuseDrift enables High-Performance Distributed Computing
- through Real-Time Processing and Auto-Scaling
- Engine Pipeline Management

## Technology Stack

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/FuseDrift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

FuseDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
